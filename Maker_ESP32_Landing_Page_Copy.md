## Trust / FAQ

**Header:** Common questions from first-time ESP32 learners.

**Does it work with my existing NodeMCU code?**
> Yes. Maker ESP32 keeps the same GPIO breakout and pin layout, so existing NodeMCU ESP32 code and tutorials work without changes.

**What driver do I need?**
> A CH9102F USB driver, linked in the Getting Started guide.

**Is it compatible with Arduino IDE?**
> Yes, along with ESP-IDF.

**Is the module certified?**
> Powered by an ESP32-WROOM-32E wireless module type-approved by SIRIM under Cytron Technologies.
